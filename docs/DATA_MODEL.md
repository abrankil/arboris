# Data model

## Status

No implementation schema has been defined. This document records concepts present in the stated product purpose without prescribing entities, fields, relationships, or storage technology.

## Scope concepts

| Concept | Connection to the stated purpose |
| --- | --- |
| Native Chilean flora | The subject of exploration and identification. |
| Observation | One of the activities the application will support. |
| Documentation | One of the activities the application will support. |
| Assisted identification | One of the activities the application will support. |

These concepts are not yet database tables or API models.

## Open decisions

- What information an observation or documentation record contains.
- How flora information is represented and sourced.
- What assisted identification receives and produces.
- Which relationships and validation rules are needed.
- Whether and how information is persisted.

Required fields, identifiers, cardinalities, and a concrete schema remain undefined until the relevant requirements are established.
