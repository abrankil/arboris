# Roadmap

This roadmap follows the [product vision](PRODUCT_VISION.md) and the 15 mandatory [product principles](PRODUCT_PRINCIPLES.md). It establishes MVP scope without selecting technologies or committing to release dates.

## 1. Establish repository documentation — current stage

- Record the exploration and collection vision and its scientific layer.
- Preserve the mandatory product principles.
- Record the shared observation domain and separation of game and scientific experiences.
- Maintain architecture, data-model, and planning documentation.

This stage is documentation only. No application code or external dependencies are part of this work.

## 2. Clarify remaining product details — pending

Define detailed workflows within the approved vision, including sufficient evidence for unlocking and the handling of unresolved discoveries without hiding uncertainty. Record the identity and source documentation of the one pilot area and six already-selected native species when supplied; their names are not specified in the current repository documentation.

The objective is to validate the complete exploration → observation → assisted identification → discovery → collection loop, not to maximize species count.

## 3. Define the technical design — pending

Evaluate technologies against the approved vision and mandatory principles before selecting a framework. Define the shared observation domain, separate game and scientific experiences, canonical species knowledge, and offline-first field functionality. Preserve evidence, context, uncertainty, variation, history, and provenance.

Record the concrete architecture and data model with decision rationale before implementation.

## 4. Plan and validate version 0.1 — pending

The complete initial playable universe consists of one pilot geographic/ecological area and six already-selected, documented native species.

Approved MVP scope:

- Species collection.
- Undiscovered/discovered state.
- Field observation.
- Photographs.
- Assisted identification.
- Evidence-based unlocking.
- Species cards.
- Collection progress.

Plan implementation tasks and validation criteria for that scope. First prove that finding a real native plant and unlocking it in Árboris is useful, understandable, scientifically responsible, and fun. The underlying observations must retain scientifically useful information, and scientific access must not depend on the gamified presentation.

Implementation is not authorized by this documentation task. Timing remains undecided.

## Beyond the initial MVP

Do not add social networks, leaderboards, competitive mechanics, complex achievements, cloud synchronization, or other large systems merely because they are common in games. These remain future product decisions.

Downloadable geographic/ecological packages remain an eventual mandatory capability under the product principles; their delivery timing and technical design are not yet defined.
