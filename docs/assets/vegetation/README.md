# Referencias vegetales canónicas

Estas referencias PNG fueron subidas por Alejandra a la carpeta [Proyecto Árboris / Arte](https://drive.google.com/drive/folders/1yNEzYZhGzIvUid_jsBkARPm-vXpYVGE9). Se consideran referencias canónicas para estudiar composición, silueta, escala, paleta y presencia de vegetación en los entornos.

Los archivos originales permanecen en Drive y no se sustituyen automáticamente por estas referencias. Para producción, cada asset debe limpiarse o redibujarse en Pixelorama conservando píxel 1:1, alpha real y coherencia con la especie y el plano del escenario.

## Regla de integración

- Referencia original: conservar en Drive.
- Asset de trabajo: redibujar o limpiar manualmente si no coincide con el lenguaje de Árboris.
- Escena: componer sobre capas de 480×270 px.
- Escalado: únicamente múltiplos enteros con `nearest-neighbor`.
- Contraste: reducir detalle y saturación en planos lejanos; reservar la máxima lectura para personajes y plano jugable.
- Estado actual: referencia canónica, no asset de producción aprobado.
